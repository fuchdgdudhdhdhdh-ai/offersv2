# Offer bot

Бот NFT-офферов: отправитель создаёт оффер на подарок, получатель принимает и передаёт подарок,
админ подтверждает получение, выплата зачисляется в течение 1-24 часов.

## Запуск на Render

1. Залей репозиторий на GitHub.
2. Render → New → Blueprint → выбери репозиторий (подхватит `render.yaml`).
3. Заполни `BOT_TOKEN`, `ADMIN_IDS`, `GIFTS_TO`.
4. `WEBHOOK_SECRET` сгенерируется сам, `WEBHOOK_BASE_URL` = `https://<имя-сервиса>.onrender.com`.
5. Deploy.

Локально: заполни `.env`, убери `WEBHOOK_BASE_URL` — бот уйдёт в polling.

## Сценарий

1. Пользователь `/start` → меню. Без баланса создание оффера заблокировано.
2. Вы: `/admin` → выдаёте баланс (или пополнение Stars).
3. Пользователь создаёт оффер → получателю приходит карточка.
4. Получатель «Принять» → «Передать NFT» (`tg://send_gift?to=<отправитель>`) → «Я передал».
5. Вы: `/admin` → «Подтвердить получение» → получатель видит «Сделка завершена» и срок выплаты.
6. Вы: «Ожидают выплаты» → «Выплатить».

## Важно

- Бесплатный план Render: SQLite обнуляется при деплое и засыпании, сервис спит 15 минут.
  Для сохранности — платный Disk и `DB_PATH=/var/data/bot.db`.
- `WEBHOOK_SECRET` входит в путь URL и в заголовок, менять только вместе с редеплоем.
- Все ошибки пишутся в stdout и `logs/bot.log`, дублируются админам.
